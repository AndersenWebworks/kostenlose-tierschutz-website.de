# Deployment

Die Seite ist als statisches Projekt angelegt und kann ohne Build-Schritt deployt werden.

## Dateien

Für den Live-Upload werden benötigt:

- `index.html`
- `assets/`
- `robots.txt`
- `sitemap.xml`
- `site.webmanifest`
- optional `CNAME`, falls GitHub Pages genutzt wird

## Domain

Produktionsdomain:

`https://kostenlose-tierschutz-website.de/`

Vor Livegang prüfen:

- Impressum und Datenschutz ergänzen oder verlinken
- echte Fotos statt Platzhalter einsetzen
- finale Kontaktadresse bestätigen
- Sitemap-Domain nach Bedarf mit oder ohne `www` angleichen
